# 水豚噜噜轻量桌宠

这是复用现有原生 Win32 + GDI+ 动画内核制作的独立桌宠，不依赖 Python、Electron 或 WebView。

## 运行与互动

- 双击 `run.bat` 启动，默认缓动跟随鼠标并保持距离。
- 跟随时左右脚交替行走，模型保持正立，不再让整张图片旋转或压缩。
- 待机会自然眨眼；约 20 秒没有鼠标移动后会坐下犯困，移动鼠标即可醒来。
- 单击噜噜会举手打招呼；左键拖动可关闭跟随并手动摆放。
- 右键可恢复/暂停跟随、回到桌面右下角或退出。
- 使用独立的窗口类和单实例锁，可与吉伊桌宠同时运行，但自身不会重复启动。

## 构建

```powershell
.\build.ps1
```

产物位于 `build\capybara-lulu-pet.exe`，运行时读取同目录下的 `assets\lulu.png`。

## 开机启动

- 双击 `build\一键启用开机启动.bat`，为当前 Windows 用户创建启动快捷方式。
- 双击 `build\一键取消开机启动.bat`，移除快捷方式且不删除桌宠文件。
