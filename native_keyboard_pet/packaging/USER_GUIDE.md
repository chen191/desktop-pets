# 火焰小蓝桌宠使用说明

## 发给别人

直接发送完整 ZIP。对方必须先把 ZIP 全部解压，再双击 `START.bat`；不要只发送 EXE，也不要在压缩包预览窗口里直接运行。

程序支持 Windows 10/11 64 位，不需要安装 Python、编译器或额外运行库，也不需要管理员权限。请把整个解压文件夹放在一个固定位置，因为 EXE 需要读取旁边的 `assets\actions` 动画素材。

## 动作

- 打字时怒敲键盘，打字越快动画越快。
- 没有持续打字时，偶尔眨眼、微笑或挥手；普通鼠标活动不会切换动作。
- 整台电脑约 45 秒无操作后睡觉，重新操作立即醒来。
- 单击立即卖萌，左键拖动位置，右键可以复位或退出。
- 右键打开“桌宠大小”，可选小号 96px、标准 128px或大号 160px；全新启动默认标准，选择会在下次启动时保留。

程序不安装全局鼠标钩子。键盘监听只统计活动时间与数量，不读取或保存具体按键；睡眠判断只读取 Windows 提供的整机空闲时长。

## 开机启动

- 双击 `Enable-Startup.bat`：为当前 Windows 用户创建启动快捷方式，无需管理员权限。
- 双击 `Disable-Startup.bat`：移除快捷方式，不会删除桌宠。
- 如果之后移动了解压文件夹，请重新运行一次启用脚本以更新路径。

## Windows 安全提示

当前是未购买代码签名证书的个人原型，首次运行时 Windows SmartScreen 可能提示“未知发布者”。只应从可信发送者处接收，并可使用同目录 `SHA256SUMS.txt` 核对 EXE。公开分发前建议进行正式代码签名。

角色素材基于用户提供的图片制作。若该角色属于第三方作品，公开发布或商业使用前需要确认相应授权。
