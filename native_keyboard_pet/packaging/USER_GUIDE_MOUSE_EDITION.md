# 火焰小蓝桌宠·鼠标版

这是根据用户选定的四帧小鼠标垫素材单独保留的 Mouse Edition，不会覆盖无鼠标版。

## 使用

- 完整解压 ZIP 后双击 `START.bat`。
- 打字时怒敲键盘，打字越快动画越快。
- 移动、点击或滚动鼠标时播放选定的四帧鼠标动作。
- 没有持续操作时偶尔卖萌；整台电脑约 45 秒无操作后睡觉。
- 单击立即卖萌，左键拖动位置，右键可切换大小、复位或退出。

程序只保留键盘和鼠标事件发生的时间，不读取或保存具体按键、输入文字、鼠标坐标或点击位置。

## 开机启动

- 双击 `Enable-Startup.bat`：为当前用户创建“Flame Keyboard Pet Mouse Edition”启动快捷方式。
- 双击 `Disable-Startup.bat`：移除该快捷方式，不影响无鼠标版的开机启动设置。

程序支持 Windows 10/11 64 位，不需要管理员权限或额外运行库。当前为未购买代码签名证书的个人原型，首次运行时 Windows SmartScreen 可能提示“未知发布者”。
